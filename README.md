# EcoRevive

## Description du site Web 
Notre site Web se nomme EcoRevive, il a pour objectif de favoriser le recyclage des articles utilisés. 
Le client peut choisir l'un des services suivants : 
* Service de Réparation
* Recycler un article
* Boutique : magasiner pour acheter un article
* Faire un don
* Un client peut s'inscrire, se connecter pour bénéficier des fonctionnalités particulières
* Finalement, nous avons intégré un chatbot dans notre site, dans le but de répondre aux questions régulièrement posées par les usagers

## Acceuil
* C'est la page principale du site
* Elle contient la description officielle du site et les liens vers les autres pages
* On peut aussi y voir les différentes statistiques et les avis des utilisateurs
