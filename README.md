# EcoRevive

## Description du site Web 
Notre site Web se nomme EcoRevive, il a pour objectif de favoriser le recyclage des articles utilisés. 
Le client peut choisir l'un des services suivants : 
* Service de Réparation
* Recycler un article
* Boutique : magasiner pour acheter un article
* Faire un don
* Finalement, un client peut s'inscrire, se connecter pour bénéficier des fonctionnalités particulières
